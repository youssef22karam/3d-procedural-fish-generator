# 🐟 3D Procedural Fish Generator

An interactive, web-based 3D procedural fish generator built with **Three.js** and HTML5/JavaScript. This project expands upon the 2D procedural generation concepts created by Lingdong Huang into an interactive 3D browser application.

---

## ✨ Features

* **3D Procedural Generation**: Generates infinite unique 3D fish shapes, fins, and textures on the fly.
* **Interactive 3D View**: Pan, rotate, and zoom around generated models in real time with WebGL.
* **Zero Dependencies Setup**: Runs entirely in the browser without requiring external build tools or backend servers.
* **Lightweight & Fast**: Pure client-side rendering powered by Three.js.
